# gongoozler (Python)

The library a run file imports: progress events (into a shared-memory ring under a supervisor),
parameters, the feed contract, catalog feeds, the Nautilus drivers, and results with a manifest.
It has no dependencies; `gongoozler.nautilus` and `gongoozler.catalog` need `nautilus_trader`.
See the repository's [README](../README.md) and [spec/](../spec).
